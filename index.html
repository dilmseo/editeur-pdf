Questions fréquentes

Ce qu'il faut savoir avant de commencer.

Combien ça coûte ?

Rien, et il n'y a rien à acheter : pas de version payante, pas d'essai limité, pas de filigrane. Y compris la correction du texte existant et la reconnaissance des scans, que les services en ligne réservent presque tous à leurs formules payantes. La raison est simple : chez eux, chaque document consomme du temps de serveur. Ici, c'est votre ordinateur qui travaille, donc il n'y a rien à facturer.

Mon fichier est-il vraiment confidentiel ?

Oui. Le PDF est ouvert et modifié par votre navigateur ; aucune donnée n'est envoyée. Le site ne contient d'ailleurs aucun code serveur : il ne pourrait pas recevoir votre fichier même s'il le voulait.

Le texte masqué est-il vraiment effacé ?

Non, et c'est important : le texte remplacé est recouvert visuellement mais reste présent dans le fichier — un copier-coller peut le retrouver. Pour supprimer réellement une donnée sensible, masquez la zone puis réimprimez le résultat en PDF (Imprimer → Enregistrer au format PDF) : l'ancien texte disparaît pour de bon.

La police d'origine est-elle conservée ?

Le texte est réécrit dans une police standard proche (Helvetica, Times ou Courier), choisie automatiquement d'après le document, avec le gras détecté. Sur une police courante le résultat est très proche ; sur une police très typée, la différence se voit. Vous pouvez la corriger à la main dans le panneau de droite.

Ça marche avec un document scanné ?

Oui. Si la page est une image, le bouton OCR analyse le document et transforme chaque ligne reconnue en bloc modifiable. La reconnaissance est en français et tourne entièrement sur votre machine.

Y a-t-il une limite de taille ou de pages ?

Aucune limite imposée. La seule contrainte est la mémoire de votre ordinateur ; les pages sont affichées au fur et à mesure du défilement pour rester fluide.

Puis-je l'utiliser hors connexion ?

Oui. Une fois la page chargée, vous pouvez couper Internet. Le code est également téléchargeable depuis le dépôt public pour un usage entièrement local.
