Licence et code source

VoilàPDF est un logiciel libre publié sous licence GNU AGPL version 3. Le code source complet est consultable sur GitHub.

Vous pouvez l'utiliser, l'étudier, le modifier et le redistribuer, y compris à des fins commerciales. La contrepartie tient à l'article 13 de cette licence : si vous exploitez une version modifiée accessible par un réseau, vous devez en proposer le code source à ses utilisateurs.

Les bibliothèques tierces embarquées restent sous leurs propres licences : pdf.js et tesseract.js sous Apache 2.0, pdf-lib et fflate sous licence MIT, transformers.js sous Apache 2.0. Le détail figure dans le fichier README du dépôt.

Limites du service

Les outils sont fournis gratuitement et sans garantie, conformément aux termes de la licence. Chaque page d'outil indique précisément ce que la conversion conserve et ce qu'elle perd ; ces limites sont réelles et documentées, nous vous invitons à les lire avant de traiter un document important.

Deux points méritent d'être rappelés ici. La modification de texte recouvre l'ancien contenu sans le supprimer du fichier : ce n'est pas un caviardage. La signature manuscrite proposée est l'équivalent numérique d'un paraphe, non une signature électronique qualifiée au sens du règlement eIDAS.

Conservez toujours une copie de vos documents d'origine.

Données personnelles

Le traitement des données est décrit dans la page Confidentialité. En résumé : aucun cookie, aucune mesure d'audience, et vos documents ne quittent pas votre ordinateur.

Liens et signalement

Le site renvoie vers des ressources extérieures dont nous ne maîtrisons pas le contenu. Pour signaler un contenu illicite, une erreur ou un dysfonctionnement, utilisez la page Nous écrire.
